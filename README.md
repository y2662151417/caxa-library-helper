# CAXA 图库助手

Windows 桌面半自动助手，用于管理本机 EXB 图纸任务，并通过紧凑悬浮面板辅助 CAXA 2024 操作。

> 本仓库只发布程序源码、通用示例和更新清单。**不收集、不上传、不提交用户的 EXB 图纸、工作副本、图号清单、块名称清单、进度数据库、个人模板或本机日志。**

## 使用环境

- Windows 10/11，64 位优先。
- Python 3.10+，安装时包含 Tkinter。
- CAXA 2024。
- 第一次启动 CAD 控制器时，需要访问 AutoHotkey 官方 GitHub Release 下载便携运行时；下载包固定 SHA-256 校验。

## 启动

解压发布包后，双击根目录唯一入口：`启动CAXA助手.bat`。程序代码位于 `app/`，稳定启动器与更新器位于 `runtime/`，本机用户数据保存在 `%LOCALAPPDATA%\CAXA_Library_Helper`。

## 隐私与网络行为

- EXB 文件仅在本机扫描文件名、大小、修改时间并创建工作副本；本工具不解析或上传 EXB 图元内容。
- 图纸清单、正式块名称清单、SQLite 进度库、用户模板、诊断结果和日志均留在本机。
- 网络请求仅用于从本仓库的 GitHub Raw 地址读取公开更新清单/程序文件，以及从 AutoHotkey 官方 GitHub Release 下载已校验的便携运行时。程序没有将本机图纸或个人数据库上传的功能。
- 更新器只允许更新 `app/` 和 `runtime/`；拒绝修改本机数据目录、根启动入口、更新源配置和日志。
- `.gitignore` 已排除 EXB、CAD 导出、数据库、个人配置、备份、日志及凭据。提交前仍应人工检查 Git 变更列表。

## 增量更新

客户端读取 `updates/manifest.json`，逐文件比较 SHA-256，只下载变化的 `app/`、`runtime/` 文件。所有文件先下载并校验，再备份旧文件并替换；失败时回滚。正常更新不需要重新下载完整安装包。

发布流程见 [`docs/更新机制说明.md`](docs/更新机制说明.md)。

## 当前限制

这是半自动辅助工具，不是 CAXA 官方插件。颜色归层、重复线选集、视图框选、基点、属性确认及最终入库仍需操作者核验。离线测试不等于 Windows + CAXA 2024 实机验收。
