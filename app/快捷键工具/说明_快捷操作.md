# CAXA 快捷控制器说明 v0.41.0

## 运行依赖

AutoHotkey v2 不要求用户单独安装。助手首次启动控制器时，会从 AutoHotkey 官方 GitHub v2.0.32 release 下载便携 ZIP，并校验固定 SHA-256。运行时保存在 `%LOCALAPPDATA%\CAXA_Library_Helper\runtime\AutoHotkey_2.0.32`；不写注册表、不设置文件关联、不需要管理员权限。首次下载需要网络。Python 3.10+（包含 Tkinter）和 CAXA 2024 仍需本机具备。

## 日常操作入口

日常操作从悬浮面板执行：

- 连接当前 CAXA；
- “开始定义图符”：启动 CAXA 原生 `symdef` 命令，并自动输入当前任务视图计划的数量（1–6）；
- “清理图纸”：启动 CAXA 原生删除重线命令，选集和删除确认仍由操作者完成；
- 颜色过滤／属性面板：启动 `objectset`、`properties`，选集和属性修改由操作者完成；
- 图符入库窗口出现后，若正式块名称已按完整图号唯一匹配且名称框完成校准，助手会自动填写并读回核对；
- 属性编辑、标题栏属性填入和最终入库仍保留明确的人工检查与确认。

## 首次控件校准

从悬浮面板点“首次校准”。定义图符已改为调用 CAXA 原生命令，不再需要校准定义按钮。其他控件校准时，面板会暂时隐藏，控制器激活当前工作副本并给出约5秒时间；把鼠标移到目标控件上，不要点击。

- “属性编辑”：先打开包含该按钮的 CAXA 属性／图符入库弹窗，再校准。
- “填入当前标题栏属性值”：先打开包含该按钮的属性编辑弹窗，再校准。
- “图符名称”输入框和图符入库“完成”按钮：先打开“图符入库”窗口，再分别校准。

若名称框不是可读写的标准 Windows 控件，自动填写会拒绝执行；此时使用“复制正式块名称”后手动粘贴。若按钮窗口标题、类别或位置变化，校准失效，工具拒绝点击，需重新校准。

## 多视图定义与图库入库

1. 在工作台选中当前图纸，创建／打开工作副本，核对图号和图符名称，并建立当前图纸的视图计划。正式名称自动填写要求正式块名称清单已按完整图号唯一匹配。
2. 定义图符前，先在图纸中准备好所有需要的视图，包括带尺寸和无尺寸版本；按既定流程完成尺寸线层处理、视图对齐及清图。视图计划顺序由工作台提供，单个图符最多六项。
3. 回到悬浮面板，直接点击“开始定义图符”。助手核对当前工作副本和任务签名，启动 CAXA 原生 `symdef` 命令，并自动输入视图数量。无需再启动人工视图引导，也不需要每完成一项就点击“下一视图”。
4. CAXA 会依次提示每个视图：框选该视图的全部图元，右键确认选集，再指定该视图基点；随后继续下一视图。框选范围和基点仍由操作者判断，助手不代替选择图元或指定基点。
5. 如果选择的视图包含尺寸，CAXA 可能提示为尺寸指定变量名。制作固定图符时，按 CAXA 提示用右键跳过变量定义；如果需要参数化图符，则应按实际设计要求定义变量，不能直接跳过。
6. 最后一个视图和基点完成后，CAXA 原生流程会打开图符入库窗口。若名称框已校准且正式块名称唯一匹配，助手会自动填写名称并读回核对；否则手动填写。类别、属性内容仍需检查。
7. 核对图库类别、名称和标题栏属性后，点击“确认并完成入库”。助手会再次核对当前工作副本、名称字段和完成按钮是否属于同一个图符入库窗口；只有人工明确确认后才点击一次“完成”。如 CAXA 弹出覆盖确认，助手不会替你选择。
8. 入库后仍需在 CAXA 中重新插入图符，核对视图、基点、尺寸版本和属性，再回工作台逐项复核。

如果定义命令被取消，需要先在 CAXA 按 Esc 结束当前命令，再按 `Ctrl+Alt+Shift+F6` 清除助手中的旧定义会话，之后重新启动。不要在旧命令仍运行时重复点击“开始定义图符”。

## 安全边界与验证状态

- 自动化只负责启动原生 `symdef` 并输入已核对的视图数量；不自动框选 CAD 图元、不替用户指定基点。
- 不自动切换尺寸线层可见性，不自动修改颜色／图层／线型属性；`objectset` 与 `properties` 只启动 CAXA 原生界面。
- 不自动确认 CAXA 的覆盖提示，不自动选择对象、不自动确认删除、不自动保存 EXB。
- 自动填写名称仅在正式名称唯一匹配、当前任务签名有效、名称框控件已校准且读回一致时执行；不会自动点击入库完成。
- 本次代码已按 CAXA `symdef` 的公开操作流程实现命令启动和视图数量输入，但尚未在用户电脑的 CAXA 2024 实机验证。首次测试必须使用工作副本或虚构图纸；若命令提示与预期不同，按 Esc 取消并反馈界面截图。
