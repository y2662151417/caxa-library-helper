# CAXA 助手操作说明 v0.42.15

## 日常使用

## 日常选图

标准启动时，完整批量管理工作台默认隐藏。点击悬浮助手中的「选择图纸」，打开紧凑选图窗口。选中图纸后，点击唯一主操作「打开图纸」；也可以双击列表行。助手会先创建工作副本，再请求打开，不会直接编辑源 EXB。名称清单导入、备份、导出和人工验收等低频管理功能位于「更多管理」，不再出现在日常选图窗口。


日常操作只使用一个「CAXA 制作助手」悬浮窗口。清理、定义图符、属性入库、视图计划和设置均在同一窗口内切换，不再层层打开新窗口。

主界面只显示当前图纸、正式块名称匹配状态、当前建议操作和简要状态。需要清理或入库时，进入「更多操作」；需要切换图纸时进入「图纸管理」。

## 操作入口

- 「继续当前任务」：根据本地图纸记录提示下一项工作。
- 「更多操作」：按需进入清理图纸、开始定义图符、属性与入库、视图计划或连接 CAXA。
- 「设置」：只保留模板选择、模板切换偏好和一次性控件校准。
- 「清理图纸」中新增颜色归层：先在 CAXA 拾取过滤中选择源颜色，再由助手按当前过滤条件执行 Ctrl+A；检查高亮范围后，应用目标图层并将颜色、线型、线宽统一设为 ByLayer。默认红色→中心线层、绿色→虚线层；白色暂不自动映射。

## 单键快捷键

所有功能键均为单键，不需要同时按 Ctrl、Alt 或 Shift。助手控制器运行且当前任务对应的 CAXA 进程处于前台时，会优先接管对应按键；暂停后将这些按键交还给 CAXA。Pause 是全局暂停/恢复键。

| 按键 | 功能 |
|---|---|
| F3 | 填入正式图符名称 |
| F4 | 全部打开图层（不改变冻结、锁定状态） |
| F5 | 开始定义图符 |
| F6 | 开始／下一视图 |
| F7 | 上一视图 |
| F8 | 打开 CAXA 图层设置；单层关闭、多层打开仍使用 CAXA 原生图层管理功能 |
| F9 | 复制正式名称 |
| F10 | 属性编辑 |
| F11 | 填入标题栏属性 |
| F12 | 查看助手状态 |
| Pause | 暂停／恢复助手快捷键；暂停时 F3–F12 交还 CAXA |

快捷键只在对应的 CAXA 任务窗口/进程前台条件满足时生效，不会在浏览器、文档编辑器等其他程序中拦截 F3–F12。助手暂停后，CAXA 原生快捷键恢复。当前按键映射固定，不提供多键组合，也不修改 CAXA 自身的快捷键配置。

## 颜色归层（首次使用需校准一次）

**首次配置目标图层**

1. 确认当前 CAXA 工作副本中已存在「中心线层」和「虚线层」，并预先将各图层的颜色、线型、线宽设置为公司标准。助手不在每张图纸上重复设置图层特性。
2. 默认映射为红色→中心线层、绿色→虚线层；白色暂不自动映射，避免在标准未确认前擅自归层。
3. 在 CAXA 主窗口显示「常用→特性」面板或颜色图层工具条。
4. 悬浮助手 → 设置 → 首次校准，分别校准图层、颜色、线型、线宽四个下拉框。每次点击对应按钮后，5 秒内将鼠标移到对应下拉框上，不要点击。只有标准 Windows ComboBox/ComboBoxEx32 控件会启用自动化；自绘控件会停止，不会猜测坐标。

**日常操作**

1. 在「清理图纸」选择源颜色规则，点击「打开拾取过滤」，在 CAXA 中设置对应颜色条件，并关闭拾取过滤对话框。
2. 点击「自动选中过滤对象（Ctrl+A）」。CAXA 会按当前拾取过滤条件全选符合条件的对象。
3. 检查高亮范围。Ctrl+A 选择的是全图中符合过滤条件的对象，并不会自动识别机械视图边界。若包含图框、标题栏、尺寸、文字、块或其他不应修改的对象，按 Esc 取消；保留颜色过滤条件，改为手动框选机械视图范围。
4. 确认当前选集正确后，点击「应用目标图层并设为随层」。助手会先将选集颜色、线型、线宽设置为 ByLayer，再设置目标图层，并对四个字段逐项读回核验。
5. 检查最终颜色、线型和线宽是否与目标图层预设一致。首次必须使用虚构测试图验证；确认无误后再用于正式工作副本。
6. 点击「恢复拾取过滤」，在 CAXA 中恢复默认/全选过滤条件。助手不会自动保存图纸。

**技术限制**

- CAXA 2018 用户手册说明，拾取过滤会影响 Ctrl+A 的选择范围；选中对象后，特性面板/工具栏的图层、颜色、线型等下拉菜单可修改选中对象属性。CAXA 2024 是否使用可被 Win32 控件接口可靠操作的标准下拉框，仍需实机核验。
- 当前版本仍需操作者在 objectset 对话框中手动设置源颜色过滤条件；自动填写过滤颜色尚未实现，需要依据 CAXA 2024 只读控件诊断继续开发。
- 如果某个下拉框不是标准 ComboBox/ComboBoxEx32、目标值无法读回，助手会停止，不会改用固定坐标点击。
- 如果中途读回失败，可能已经修改了部分属性；请检查选集，必要时在 CAXA 中撤销，再重新校准。
- 本流程只修改当前工作副本中的当前选集，不自动保存 EXB。

## 图符定义

视图计划建立后，悬浮面板主按钮直接启动定义图符，不再先跳转到“CAD 制作提示”页。控制器校验任务签名和工作副本后调用 CAXA 原生 symdef，并自动输入4项或6项视图数量。首次使用时若未绑定 CAXA，会从当前工作副本窗口完成一次连接确认。视图选集、每组基点以及尺寸变量判断仍按 CAXA 原生命令提示完成；Symdef 是否按预期连续衔接各组、最后是否自动打开入库窗口，仍需在 Windows + CAXA 2024 实机验证。最后一组完成后自动打开图符入库窗口；名称控件已校准且正式名称唯一匹配时，助手自动填写名称。

当前代码尚未在用户电脑的 CAXA 2024 实机验收；不能把启动原生命令等同于完成六视图自动化。后续以真实 CAXA 操作验证连续选图和自动衔接。

## 控制器启动诊断

首次启动需要下载并校验 AutoHotkey 官方便携运行时。控制器必须写入与当前进程 PID 一致的标记，悬浮面板才会显示“已连接”。旧版 UTF-8 BOM 标记也可读取；新版写入不带 BOM，避免 PID 被误判。启动语法错误日志：

%CAXA_HELPER_DATA_DIR%\ahk_controller_startup.log

若 PID 标记写入失败，另查 %CAXA_HELPER_DATA_DIR%\ahk_controller_marker_error.log。日志只保存在本机，不包含 EXB 图纸内容。启动程序会等待真实 PID 注册，不再把“进程已创建”误报为“控制器已连接”。

## 只读控件诊断

在「更多操作」中点击「只读诊断 CAXA 控件」。工具会自动枚举当前任务绑定的 CAXA 进程中所有可见顶层窗口，并在一次扫描中记录主绘图窗口、停靠面板及当前可见对话框的窗口类名、控件类名（ClassNN）、真实 Win32 类名、控件 ID、窗口样式、可见/启用状态和位置。该信息用于区分标准按钮、编辑框、列表控件及自绘控件，不会直接触发任何 CAD 操作。

如果要检查某个尚未打开的 CAXA 对话框，先在 CAXA 中打开该对话框，再点击一次诊断；本次扫描会同时包含同一 CAXA 进程中所有可见窗口。工具不会主动打开对话框、激活窗口、点击控件或发送 CAD 命令。

报告不输出窗口标题、控件文本、图纸内容、参数或截图；窗口标题只在本机用于核验当前工作副本身份，不写入报告。每份报告最多记录 20 个可见窗口、每窗口最多 300 个控件、总计最多 1200 个控件。报告写入当前配置的数据目录下的 diagnostics 子目录。自绘控件或 UIA-only 控件可能无法通过 Win32 控件枚举发现。

## 安全边界

- 不自动框选 CAD 图元、不替用户指定基点。
- 不自动确认删除、覆盖提示或最终图库入库。
- 不自动保存 EXB。
- 不把本地建议名称冒充正式块名称；只有按完整图号唯一匹配时才使用正式名称。
- 颜色规则、属性字段和 CAD 控件未完成公司标准确认或 CAXA 2024 实机验证前，不执行未经核实的自动修改。
