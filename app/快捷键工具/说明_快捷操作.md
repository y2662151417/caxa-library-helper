# CAXA 快捷控制器说明 v0.37-dev

## 运行依赖

AutoHotkey v2 不要求用户单独安装。助手首次启动控制器时，会从 AutoHotkey 官方 GitHub v2.0.32 release 下载便携 ZIP，并校验固定 SHA-256。运行时保存在 `%LOCALAPPDATA%\CAXA_Library_Helper\runtime\AutoHotkey_2.0.32`；不写注册表、不设置文件关联、不需要管理员权限。首次下载需要网络。Python 3.10+（包含 Tkinter）和 CAXA 2024 仍需本机具备。

## 日常操作入口

日常操作从悬浮面板执行，不要求记快捷键：

- 连接当前 CAXA；
- 悬浮面板“删除重复线”（只启动 `eraseline`，对象范围和删除确认由操作员完成；不自动选择对象）；
- 颜色过滤／属性面板（启动 `objectset`、`properties`，选集和属性修改由操作员完成）；
- 开始视图引导、启动定义图符、上一视图／下一视图；
- 属性编辑、填入当前标题栏属性值；
- 正式块名称填写；
- 最终入库确认（有条件门槛，且只点击一次已校准的“完成”按钮）。

## 首次控件校准

从悬浮面板点“首次校准”。校准窗口会暂时隐藏，控制器激活当前工作副本，随后给出约5秒时间把鼠标移动到目标按钮／输入框上；不要点击。校准只记录控件所在窗口、类别及位置，不执行 CAD 命令。

- “定义图符”：在 CAXA 工作副本主绘图窗口校准。
- “属性编辑”：先打开包含该按钮的 CAXA 属性／图符入库弹窗，再校准。
- “填入当前标题栏属性值”：先打开包含该按钮的属性编辑弹窗，再校准。
- “图符名称”输入框和图符入库“完成”按钮：先打开“图符入库”窗口，再分别校准。

若名称框不是可读写的标准 Windows 控件，自动填写会拒绝执行；此时使用面板“复制正式块名称”后手动粘贴。若按钮窗口标题、类别或位置变化，校准失效，工具拒绝点击，需重新校准。

## 六视图与图库入库流程

1. 在工作台选中当前图纸，创建／打开工作副本，导入正式块名称清单并确认当前图号唯一匹配。
2. 在工作台建立当前图纸的视图计划。当前发送给 CAXA 的顺序是：所有“带尺寸”视图先完成，再处理所有“无尺寸”视图；同一组内按工作台视图类型顺序。
3. 在悬浮面板点击“开始视图引导”，核对工作副本；点击“启动定义图符”后，按 CAXA 命令提示手动框选、确认选集并指定基点。
4. 每完成一项视图和基点，点击面板“下一视图”。如需要回看，点击“上一视图”。进度只记录人工确认，不证明 CAD 已成功创建对象。
5. 全部带尺寸视图完成后，手动关闭尺寸线层（不要删除尺寸对象），再完成全部无尺寸视图；完成后恢复尺寸线层显示并检查其它图层没有被误关。
6. CAXA 打开图符入库窗口后，点击“填写正式块名称”；在属性编辑窗口使用“属性编辑”和“填入标题栏属性”按钮。名称框自动填写必须通过已校准控件读回核对。
7. 全部视图已人工确认、正式块名称唯一匹配、名称输入框读回值与清单完全一致后，面板才开放“确认并完成入库”。点击后会要求你再次确认，控制器只点击一次校准的“完成”按钮；如 CAXA 弹出覆盖确认，助手不会自动替你选择。
8. 入库后仍需在 CAXA 中重新插入图符，核对视图、基点、尺寸版本和属性，再回工作台逐项人工复核。

## 安全边界

- 不自动框选 CAD 图元、不替用户指定基点、不自动切换尺寸层可见性。
- 不自动修改颜色／图层／线型属性；`objectset` 与 `properties` 只启动 CAXA 原生界面，实际选择与修改由操作员完成。
- 不自动确认 CAXA 的覆盖提示，不自动选择对象、不自动确认删除、不自动保存 EXB。
- 最终“完成”按钮必须同时满足：当前任务签名有效、视图引导进度已到末项之后、正式块名称状态为“已匹配”、名称输入框读回值与正式块名称一致、完成按钮和名称框校准到同一个图符入库窗口，并由操作员在面板二次确认。
- 所有控件校准和点击都依赖 CAXA 2024 实际窗口；本开发环境没有 Windows + CAXA 2024，尚无实机运行证据；删除重复线、颜色辅助、视图定义和图库入库均尚待 Windows + CAXA 2024 实机验证。
