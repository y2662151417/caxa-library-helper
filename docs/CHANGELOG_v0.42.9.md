# CAXA 图库助手 v0.42.9

## 本轮范围：把日常选图从完整管理工作台中拆出来

- 标准启动模式下隐藏完整批量管理工作台，不再与小型悬浮助手同时铺满桌面。
- 悬浮助手的「图纸管理」入口改为「选择图纸」，打开独立的 680×460 紧凑选择窗口。
- 选择窗口只保留目录选择、刷新、图号/图名搜索、图纸列表、当前选择状态和「打开工作副本」主按钮。
- 单击列表只负责选中；双击列表或点击「打开工作副本」均会创建工作副本并请求打开。
- 选择窗口打开期间暂时释放悬浮助手的置顶状态，避免两个窗口互相遮挡；关闭后恢复助手置顶。
- 原完整管理工作台保留在「更多管理」入口，备份、导出、清单导入、参数记录和人工验收功能不删除。
- 「退出助手」仍通过原安全退出流程撤销当前快捷任务。

## 验证边界

- GitHub Actions 验证 Python 编译和离线单元测试。
- 仍需 Windows + CAXA 2024 实机确认窗口层级、目录选择、双击打开和工作副本打开结果。
