# CAXA 图库助手｜实际使用说明 v0.42.6

## 目录结构

- `启动CAXA助手.bat`：唯一日常启动入口。
- `app/`：工作台、悬浮面板、CAD 辅助模块及示例模板。
- `runtime/`：稳定启动器和增量更新器。
- `updates/`：更新源配置、暂存和回滚。
- `docs/`：使用说明和导入模板。
- `logs/`：本机启动与更新日志。

## 首次启动

1. 将完整程序目录解压到固定位置，不要把程序文件与公司 EXB 图纸混放。
2. 双击根目录的 `启动CAXA助手.bat`。
3. 启动器检测 Python 3.10+ 和 Tkinter，再运行悬浮面板。
4. 第一次使用 CAD 控制器时，程序会从 AutoHotkey 官方发布页下载固定版本的便携运行时，并校验 SHA-256。

## 自动更新

安装包已预配置公开 GitHub Raw 更新清单：

`https://raw.githubusercontent.com/y2662151417/caxa-library-helper/main/updates/manifest.json`

每次启动时，程序通过 HTTPS 检查版本和文件 SHA-256，只下载 `app/`、`runtime/` 中发生变化的程序文件。没有变化时不会下载程序文件。下载文件全部通过校验后才替换本机文件；更新失败时记录日志并继续启动原版本。

如果当前网络无法访问 GitHub Raw，自动更新可能暂时无法完成，但不会因此删除本机数据或阻止旧版本启动。检查状态、版本号、下载/替换文件数及失败原因会记录在安装目录的 `logs/launcher.log`。

## 本机数据

图纸扫描记录、SQLite 进度数据库、导入的正式块名称清单、用户模板、模板选择、CAD 控制器运行时和备份保存在：

`%LOCALAPPDATA%\\CAXA_Library_Helper`

这些文件不属于公共源码仓库，也不应提交到 Git。增量更新只允许修改 `app/` 和 `runtime/`，不更新用户数据目录、根启动入口或更新源配置。

## 视图模板

在悬浮助手的“设置”中，按当前批次图纸类型选择一次视图模板：

- **三视图**：主视图、俯视图、左视图；每种视图各有带尺寸和无尺寸版本，共 6 项。
- **双视图**：主视图、左视图；每种视图各有带尺寸和无尺寸版本，共 4 项。

模板保存在本机。后续尚未建立视图计划的图纸会自动沿用；已经建立的图纸计划不会因修改默认模板而被覆盖。更换图纸时不再弹出视图选择窗口。右视图、剖视图和局部视图不属于当前默认方案。

## 每张图的基本流程

1. 在图纸管理工作台选择本机 EXB 目录并扫描。
2. 导入本机正式块名称清单。
3. 在 CAD 中打开工具创建的工作副本，并连接当前 CAD 窗口。
4. 悬浮助手主按钮直接启动 CAXA 原生 Symdef，并自动输入本张4项或6项视图数量。首次使用时若尚未绑定 CAD，助手会从当前工作副本窗口完成一次连接确认。
5. 在 CAXA 中依次框选每组视图、确认选集并指定该组基点。CAXA 原生命令会自动衔接下一组，不需要返回悬浮助手点击“下一视图”。全部视图完成后，CAXA 自动打开图符入库窗口；名称控件完成一次校准且正式名称唯一匹配时，助手自动填写名称。
6. 尺寸层切换、属性填入、图库类别核对、最终入库确认和重新插入检查仍按公司要求完成；确认结果后再记录本张复核状态。

具体 CAD 选集、删除确认、视图框选、基点和最终入库均需操作者检查；离线测试不能替代 Windows + CAXA 2024 实机验收。
