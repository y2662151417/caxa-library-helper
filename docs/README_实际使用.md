# CAXA 图库助手 v0.42.17｜独立测试版实际使用说明

## 运行条件

- Windows 10/11 x64，已安装 CAXA 2024。
- **不需要在电脑上预先安装 Python，也不需要配置 Python 环境变量。**
- Python 3.11 运行环境、Tk/Tcl 图形库和应用程序已随测试包打包。
- AutoHotkey v2.0.32 便携运行时也随测试包提供；首次启动时复制到独立用户数据目录，不需要首次联网下载。
- 解压后双击根目录的 启动CAXA助手.bat。

## 悬浮面板

首页只保留日常需要的内容：

- 当前选择的图纸名称。
- 正式块名称匹配状态及“复制块名称”。
- “核对图纸”按钮，用于检查当前 CAXA 活动窗口标题是否与所选的工作副本一致。
- 清理重复线、颜色归层、打开图层设置、全部图层打开、定义图符。
- 选择图纸和设置。

不再提供“属性与入库”自动化。属性填写、属性编辑、图库入库和最终保存由操作者在 CAXA 中完成；助手只检索和复制正式块名称。

## 推荐使用顺序

1. 在悬浮面板点击“选择图纸”，扫描包含 EXB 的目录。
2. 在“设置”中导入 Excel 块名称清单。Excel 第一张工作表的前两列分别为“图号”和“块名称”。
3. 在图纸选择窗口选中一张图纸，点击“打开图纸”。程序会先创建工作副本，再请求 CAXA 打开工作副本；原始 EXB 不会被直接修改。
4. 回到悬浮面板，点击“核对图纸”。显示“CAXA：图纸匹配”表示当前活动窗口标题与所选工作副本的文件名一致；显示“无法确认”时请手动检查 CAXA 标题栏。
5. 点击“复制块名称”，将正式名称粘贴到你自己的 CAXA 图符名称字段。
6. 再使用清理重复线、颜色归层和图层操作。

普通清理/图层操作只要求已选择图纸并建立有效工作副本，不再要求先建立四项或六项视图计划。“定义图符”仍要求有效的双视图/三视图计划。

## Excel 块名称匹配

Excel 格式示例：

| 图号 | 块名称 |
|---|---|
| CRB01D2084 | CRB01D2084_垂直重锤拉紧装置_B500_08轴_D500 |

当前 EXB 文件名示例：

    CRB01D2084_垂直重锤拉紧装置.exb

程序提取第一个下划线之前的完整图号，按完整图号精确匹配。不会使用相似前缀或模糊名称猜测。一个图号对应多条清单记录、图纸目录中同图号对应多张 EXB、或找不到图号时，均不会提供可复制的候选名称。

导入的 Excel 映射保存在本机用户数据目录，不会上传到 GitHub，也不会修改 EXB。

## 常用操作安全边界

- “清理重复线”：助手启动 CAXA 原生命令，操作者自行框选范围并确认。
- “颜色归层”：仍需先设置/确认拾取过滤条件，检查高亮选集，再执行归层；不自动保存 EXB。
- “打开图层设置”：打开 CAXA 原生图层管理窗口。
- “全部图层打开”：执行 layon，仅恢复关闭状态，不解冻、不解锁。
- “定义图符”：仍依赖已核对的视图计划和 CAXA 当前界面。
- 尺寸线层开关和打散继续使用操作者已有的快捷键，不由助手重复实现。
- 助手不自动保存图纸、不自动填写属性、不自动点击最终入库。

## 独立数据目录

本测试包将数据固定保存在：

    %LOCALAPPDATA%\CAXA_Library_Helper_TEST_0_42_17

不读取或修改正式版 %LOCALAPPDATA%\CAXA_Library_Helper，也不读取迁移目录中的 UserData。自动更新关闭。升级测试包不会自动删除此 TEST 数据目录。

## 实机验收

第一次只使用自制虚构测试图，或正式图纸的独立副本。不要直接修改、保存公司正式图纸。若图纸核对不是“匹配”、按钮无响应、误选对象或出现无法确认的对话框，停止操作并截图反馈。
