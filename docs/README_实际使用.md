# CAXA 图库助手｜实际使用说明 v0.42.16

## 悬浮面板首页

首页以直接点击为主，不要求记忆快捷键。常用操作区提供六个入口：

- 清理重复线
- 颜色归层
- 打开图层设置
- 全部图层打开
- 定义图符
- 属性与入库

「继续当前任务」仍是首页主操作；「选择图纸」和「设置」位于首页底部。「其他工具」仅保留连接当前 CAXA 和只读控件诊断。颜色归层和属性入库在同一个悬浮窗口内切换到对应操作页。

本版本不注册全局快捷键，不拦截 CAXA 原生按键。图层单层开关仍使用 CAXA 原生图层管理；「全部图层打开」执行 layon，只恢复关闭状态，不解冻、不解锁。

## 目录结构

- `启动CAXA助手.bat`：唯一日常启动入口。
- `app/`：工作台、悬浮面板、CAD 辅助模块及示例模板。
- `runtime/`：稳定启动器和增量更新器。
- `updates/`：更新源配置、暂存和回滚。
- `docs/`：使用说明和导入模板。
- `logs/`：本机启动与更新日志。

## 首次启动

1. 将完整程序目录解压到固定位置，不要把程序文件与公司 EXB 图纸混放。
2. 双击根目录的 `启动CAXA助手.bat`。
3. 启动器检测 Python 3.10+ 和 Tkinter，再运行悬浮面板。
4. 第一次使用 CAD 控制器时，程序会从 AutoHotkey 官方发布页下载固定版本的便携运行时，并校验 SHA-256。

## 自动更新

正式运行包可通过 HTTPS 读取公开 GitHub Raw 更新清单，只下载 SHA-256 发生变化的 `app/`、`runtime/` 程序文件；所有文件先校验，再替换，失败时回滚。

**本次 v0.42.16 独立测试包已关闭自动更新**：其 `updates/update_source.json` 中 `auto_check=false` 且 `manifest_url` 为空，不会从 main 稳定分支下载或替换任何程序文件。后续测试版本通过新的独立 ZIP 交付。

## 本机数据

图纸扫描记录、SQLite 进度数据库、导入的正式块名称清单、用户模板、模板选择、CAD 控制器运行时和备份保存在：

`%LOCALAPPDATA%\\CAXA_Library_Helper`（正式运行包；独立测试包使用单独的 TEST 数据目录）

这些文件不属于公共源码仓库，也不应提交到 Git。增量更新只允许修改 `app/` 和 `runtime/`，不更新用户数据目录、根启动入口或更新源配置。

## 视图模板

在悬浮助手的“设置”中，按当前批次图纸类型选择一次视图模板：

- **三视图**：主视图、俯视图、左视图；每种视图各有带尺寸和无尺寸版本，共 6 项。
- **双视图**：主视图、左视图；每种视图各有带尺寸和无尺寸版本，共 4 项。

模板保存在本机。后续尚未建立视图计划的图纸会自动沿用；已经建立的图纸计划不会因修改默认模板而被覆盖。更换图纸时不再弹出视图选择窗口。右视图、剖视图和局部视图不属于当前默认方案。

## 每张图的基本流程

1. 在图纸管理工作台选择本机 EXB 目录并扫描。
2. 导入本机正式块名称清单。
3. 在 CAD 中打开工具创建的工作副本，并连接当前 CAD 窗口。
4. 悬浮助手主按钮直接启动 CAXA 原生 Symdef，并自动输入本张4项或6项视图数量。首次使用时若尚未绑定 CAD，助手会从当前工作副本窗口完成一次连接确认。
5. 在 CAXA 中依次框选每组视图、确认选集并指定该组基点。Symdef 是否按预期连续衔接下一组、全部视图完成后是否自动打开图符入库窗口，仍需 Windows + CAXA 2024 实机确认。名称控件完成一次校准且正式名称唯一匹配后，助手才会尝试自动填写名称。
6. 尺寸层切换、属性填入、图库类别核对、最终入库确认和重新插入检查仍按公司要求完成；确认结果后再记录本张复核状态。

具体 CAD 选集、删除确认、视图框选、基点和最终入库均需操作者检查；离线测试不能替代 Windows + CAXA 2024 实机验收。

## 只读控件诊断

在悬浮面板「其他工具」中点击「只读诊断 CAXA 控件」，选择当前打开的界面阶段。诊断报告保存在用户数据目录的 `diagnostics` 子目录。报告只输出进程名、窗口类名、控件类名和控件位置，不输出窗口标题、控件文字、图纸内容、参数或截图；不发送 CAD 命令、不点击、不修改或保存 EXB。第一轮必须使用自制虚构测试图，不使用公司正式图纸。

## v0.42.16 独立测试包

独立测试包使用独立的用户数据目录 `%LOCALAPPDATA%\\CAXA_Library_Helper_TEST_0_42_16`，并关闭自动更新，不读取或修改现有助手的用户数据。请解压到新的目录，并先使用自制虚构测试图；不要覆盖现有安装目录或直接修改公司正式图纸。
