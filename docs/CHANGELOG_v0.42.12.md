# CAXA 图库助手 v0.42.12

## 增强只读 CAXA 控件诊断

- 在现有一次性全窗口诊断中增加每个子控件的真实 Win32 类名、Dialog Control ID、可见状态、启用状态、GWL_STYLE 与 GWL_EXSTYLE。
- 同时保留 ClassNN、HWND 和客户区位置。
- 不读取窗口标题、控件文本、图纸内容、参数或截图；不激活窗口、不点击、不发送 CAD 命令。
- 诊断仅提供控件识别证据，不代表可以对未知控件执行自动操作。

## 验证边界

本轮是 AHK 源码级和 Python 静态安全测试增强。CI 不运行 Windows AHK，也没有 CAXA 2024 实机；后续仍需用虚构工作副本生成诊断报告。
