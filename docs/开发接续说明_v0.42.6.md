## 已确认的制作规则

- 只编辑独立工作副本，不修改原始标准图。
- 双视图：主视图、左视图，各有带尺寸/无尺寸版本，共4项。
- 三视图：主视图、俯视图、左视图，各有带尺寸/无尺寸版本，共6项。
- 所有带尺寸视图先完成，再处理无尺寸视图。
- 不把剖视图、右视图、局部视图塞入默认六项。
- CAXA 原生定义非参数化图符：每组视图分别框选、确认选集、指定该组基点；不能假设空格键等同回车。
- 图符属性必须使用 CAXA 原生“填入当前标题栏属性值”。
- 最终入库、覆盖处理、重新插入检查和完成签署仍需按公司规范复核。

## v0.42.6 本轮修改

1. 主操作按钮不再打开纯文字“CAD 制作提示”页。
2. 如果当前图纸还没有视图任务，主按钮按已保存模板建立4项或6项计划，并直接启动 CAXA Symdef。
3. 如果视图计划已经存在，主按钮直接启动 Symdef。
4. Python 和 AHK 两端均限制当前默认流程为4项或6项。
5. 首次未连接 CAXA 时，控制器从当前已发布工作副本窗口进行一次明确连接确认，减少单独点击“连接当前 CAXA”的步骤。
6. CAXA 原生命令负责连续衔接各组视图；操作者不需要每完成一组就返回悬浮窗点击“下一视图”。
7. 图符入库窗口的正式名称自动填写逻辑保留：需要控件完成一次校准，并且正式名称按完整图号唯一匹配。

## 下一步：先实机验证，不扩大自动点击范围

使用一张完全虚构、无密的测试 EXB，不要直接拿39张正式图纸测试：

1. 打开测试图纸的工作副本，确认 CAXA 标题栏与助手发布的工作副本一致。
2. 视图计划未建立时，点击主按钮，检查是否一次完成计划建立并启动 Symdef。
3. 视图计划已建立时，点击主按钮，检查是否直接启动 Symdef。
4. 首次连接时确认一次目标窗口；之后检查是否无需重复连接。
5. 检查 Symdef 是否收到正确的4项/6项数量，逐组框选、确认选集、指定各自基点时，CAXA 是否按原生命令自动进入下一组。
6. 检查最后一组完成后是否自动打开图符入库窗口；名称控件已校准且正式名称唯一匹配时，是否正确填写并读回。
7. 暂不自动点击最终入库、覆盖确认或保存；先检查窗口和命令是否稳定。

实机验证通过后，再逐项研究尺寸层开关/复制、原生属性填入、图库提交后的结果识别和下一张切换。需要先通过只读控件诊断确认 CAXA 2024 控件类型、窗口身份和可访问性，不凭坐标猜测或盲发回车。
