# CAXA 图库助手 v0.42.14

## 颜色归层流程增强

- 清理图纸窗口新增「自动选中过滤对象（Ctrl+A）」入口；执行前要求确认 CAXA 已关闭拾取过滤对话框且处于空命令状态。
- 依据 CAXA 拾取过滤规则执行 Ctrl+A；执行后必须检查高亮范围。若包含图框、标题栏、尺寸、文字、块或其他非目标对象，按 Esc 取消并改用局部框选。
- 颜色归层从单独修改图层扩展为四项属性处理：颜色 ByLayer、线型 ByLayer、线宽 ByLayer、目标图层。
- 新增四个工具栏下拉框的一次性校准；只允许标准 ComboBox/ComboBoxEx32，且应用前预检目标项、应用后逐项读回。
- 默认映射保持红色→中心线层、绿色→虚线层；白色不自动映射。
- 不自动保存图纸；尺寸层开关和打散继续使用操作者已有快捷键；无尺寸视图复制继续暂缓。
- GitHub Actions 新增 Windows 任务：下载并校验固定版本的 AutoHotkey v2 便携运行时，以 parse-only 模式检查主脚本及 include 文件语法。

## 验证边界

- CAXA 2018 用户手册支持“拾取过滤影响 Ctrl+A”及选中对象后通过特性下拉菜单修改属性的操作依据；CAXA 2024 的控件结构和行为尚未实机验证。
- 控件不是标准下拉框、目标值不存在或读回不一致时，助手停止；若操作中途失败，可能已有部分属性写入，应检查并按需撤销。
- 正式图纸使用前，必须先用虚构测试 EXB 验证选集范围、四项属性修改和最终显示效果。
