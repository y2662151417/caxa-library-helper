# CAXA 图库助手 v0.42.14

## 本轮目标

把图纸映射、颜色映射集中到同一份 Excel；缩小悬浮窗；为 CAXA 2024 拾取过滤和属性面板建立可核验的只读诊断路径。

## 已实现

- Excel 读取支持同一工作表中的 A-C 图纸映射表：图号、EXB 文件名、正式块名称。
- 导入时核验图号、EXB 文件名与正式块名称前缀；复制时按图号和 Excel 文件名精确匹配。
- 兼容原有两列图号/块名称工作簿。
- 支持颜色规则表：A-E 为目标图层、对象线型、线型比例、对象线宽、对象颜色；F 列可增加“原始颜色”以显式指定筛选源颜色。
- 当前上传的旧工作簿没有 F 列，使用用户已确认的五组默认规则：
  - 红色 → 中心线层
  - 绿色 → 虚线层
  - 蓝色 → 双点划线层
  - 洋红色 → 细实线层
  - 白色+黑白色 → 0层
- 对象颜色、线型、线宽默认 ByLayer；线型比例为 1。
- 名称映射与颜色规则在一次 Excel 导入中原子写入 SQLite；导入失败不覆盖旧数据。
- 悬浮窗缩小至约 310×230，首页直接提供颜色下拉、拾取筛选、一键设置特性、删除重线、定义属性块和复制正式块名称。
- CAXA 原生 objectset / properties 命令启动后，增加针对拾取过滤对话框和独立属性窗口的只读控件诊断；报告不读取绘图区域内容，不点击、不修改。
- 新增合并 Excel、文件名精确匹配、默认颜色规则和紧凑面板测试。

## 当前未完成 / 不得误报

- 拾取过滤对话框自动勾选颜色尚未实现；当前按钮打开 objectset 并尝试生成控件诊断。
- “全部颜色”当前打开 objectset，仍需在 CAXA 对话框中人工恢复默认/全选条件。
- 一键设置特性尚未自动写入对象；当前按钮打开 properties 并尝试生成独立属性窗口诊断。
- 如果属性面板为嵌入式停靠面板而非独立顶层窗口，当前只读探针会报告未找到，不会扫描主绘图区控件。
- AHK v2 语法、Win32 控件枚举和 CAXA 2024 模态/停靠窗口行为尚未实机验证。
- 不允许用猜测坐标或未验证的 CHPROP 等命令代替实机验证。
- 不自动填写图符属性、不自动完成图库入库、不自动提交、不自动保存 EXB。
