# CAXA 图库助手 v0.42.11

## 修复任务安全校验的视图顺序

- 修复 app/preflight.py 中发布任务与独立校验器使用不同视图排序的问题。
- 任务校验现在直接复用 core.slots_for() 的唯一顺序：先全部带尺寸视图，再全部无尺寸视图。
- 增加虚构文件与真实 SQLite 数据库的离线交接测试，覆盖双视图4项、三视图6项及错误交错顺序。
- 正确顺序的任务必须通过 active_job_valid；错误顺序仍被拒绝。
- 不改变 CAXA 命令、自动点击、图纸内容或用户数据。

## 验证边界

本轮验证的是 Python 任务发布与安全校验的一致性，不代表 Symdef、尺寸线层切换或图符入库已通过 Windows + CAXA 2024 实机测试。
