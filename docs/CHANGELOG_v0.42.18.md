# CAXA 图库助手 v0.42.18

## 修复：面板请求被错误判定为过期

- 根因：AutoHotkey v2 的 `DateDiff(DateTime1, DateTime2, ...)` 返回第一个时间减第二个时间。旧代码把 1970 年放在第一个参数、当前 UTC 放在第二个参数，得到负 Unix 时间戳，随后被请求 TTL 检查判定为过期。
- 修正为 `DateDiff(A_NowUTC, "19700101000000", "Seconds")`，得到正 Unix 时间戳。
- 增加源代码回归测试，明确锁定参数顺序，防止再次反转。

## 设置页调整

- 将“打开助手数据文件夹（诊断日志）”移到设置页顶部。
- 设置页高度略微增加，避免诊断入口被内容挤到窗口下方。
- 提示再次发生过期时应发送 `panel_action_expiry.log`。

## 验证边界

- 自动化 CI 通过后，仍需用户在 CAXA 2024 中实测颜色筛选。
- 点击颜色按钮后，助手只自动设置拾取过滤窗口的颜色勾选状态；用户仍需在 CAXA 中点击“确定”。
- 不自动选择图元、不自动确认对话框、不自动保存 EXB、不自动入库。
