## 本轮已改动

- app/core.py：增加标准库 XLSX 解析，不依赖 openpyxl；读取第一张可见工作表 A 列图号、B 列正式块名称；重复图号、重复名称、前缀不一致、空值、公式和第三列非空数据会拒绝整次导入；导入校验通过后才在事务中替换旧映射。旧 TXT/CSV 内部导入函数保留兼容，但 UI 入口只接受 XLSX。
- app/clipboard_utils.py：Windows 优先读取 CF_UNICODETEXT，Tk 只用于非 Windows 回退。
- app/cad_window.py：只读读取已绑定 CAXA 进程的窗口标题，精确核验工作副本文件名。
- app/app.py：Excel-only 导入入口；复制正式块名称前检查源图、工作副本、符号链接/硬链接及当前 CAXA 窗口；复制时不使用本地建议名称作为回退。
- app/floating_panel.py：首页增加复制正式块名称按钮；未匹配时禁用；更多操作移除属性与入库入口；剪贴板读取改用 Unicode helper。
- app/快捷键工具/CAXA_半自动辅助.ahk：快捷键复制只接受唯一正式块名称，并先核验当前窗口文件名；Symdef 后只提示人工填写，不自动填写名称；最终入库动作只提示操作者自行完成，不再执行完成按钮点击；Ctrl+Alt+F8 自动填写名称热键停用。
