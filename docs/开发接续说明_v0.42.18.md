## 本轮修复：面板请求过期误判

用户实机反馈：点击绿色筛选后，悬浮窗底部显示“已发送绿色筛选请求；等待 CAXA”，但屏幕提示“面板请求已过期；请重新点击操作按钮”，颜色筛选未执行。

### 已确认根因
旧代码：
```ahk
DateDiff("19700101000000", A_NowUTC, "Seconds")
```
AutoHotkey v2 的 DateDiff 返回 DateTime1 减 DateTime2。旧代码因此得到负 Unix 时间戳，随后 `age < -10` 恒成立（在正常当前日期下），所有新请求都会被误判为过期。

修复：
```ahk
DateDiff(A_NowUTC, "19700101000000", "Seconds")
```
当前 UTC 放在第一个参数，返回正 Unix 时间戳，再与请求的十位 epoch 秒相减。

## 用户确认的颜色规则（保持不变）
- 红色 → 中心线层
- 绿色 → 虚线层
- 蓝色 → 双点划线层
- 洋红色 → 细实线层
- 白色 + 黑白色 → 0 层

颜色按钮只更改 CAXA 拾取过滤窗口中的颜色勾选状态；用户自行点击 CAXA 对话框“确定”，再框选对象。
一键设置特性继续按 Excel 规则执行；左侧特性栏由用户核对。
不自动保存 EXB、不自动入库、不自动提交图库。

## 用户侧下一步
1. GitHub Desktop 确认当前分支为 `work/v0.42.16-controller-handshake`。
2. 点击 Fetch origin；出现 Pull origin 后点击更新。
3. 退出旧版助手和系统托盘旧版 AHK H 进程。
4. 重新运行助手，确认控制器 build ID 为 `caxa-helper-v0.42.18`。
5. 打开测试 EXB，按 Esc 清空选集，点击“绿色”。
6. 预期：CAXA 拾取过滤窗口中只勾选绿色，其他颜色取消；用户自行点击“确定”。
7. 若仍失败：助手“⋯”→设置→“打开助手数据文件夹（诊断日志）”，发送完整的 `panel_action_expiry.log`。如文件不存在，再发送 `ahk_controller_startup.log` 与 `ahk_controller_marker_error.log`（存在才发）。这些日志不应包含图纸实体内容；发送前仍可自行检查。
