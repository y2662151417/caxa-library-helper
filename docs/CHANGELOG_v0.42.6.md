# CAXA 图库助手 v0.42.6

## 本轮修改

- 主操作按钮不再打开纯文字“CAD 制作提示”页；视图任务准备完成后直接启动 CAXA 原生 Symdef。
- 已保存模板可在一次主按钮操作中建立本张4项或6项视图任务并启动定义命令。
- 双视图固定为主视图、左视图各带尺寸/无尺寸，共4项；三视图固定为主视图、俯视图、左视图各带尺寸/无尺寸，共6项。
- 首次未绑定 CAXA 时，从当前工作副本窗口完成一次连接确认，不再强制先单独点击“连接当前 CAXA”。
- CAXA 原生命令继续负责逐组视图选集和各自基点；不要求每组完成后返回助手点击“下一视图”。
- 正式块名称仍依赖一次性控件校准及完整图号唯一匹配，现有入库名称自动填写逻辑保留。

## 验证范围

- GitHub Actions：Python 编译检查及单元测试通过。
- 新增路由测试覆盖4项、6项、异常视图数量、已复核状态和一键启动路径。
- **尚未在用户电脑的 Windows + CAXA 2024 实机验证。** 本版本不声称已自动完成图元清理、尺寸层复制/切换、颜色归层、标题栏属性填入、最终入库提交、保存或重新插入检查。
