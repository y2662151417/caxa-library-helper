## 用户确认的目标

- 悬浮窗缩小，只保留当前图纸身份、当前 CAXA 图纸核对、正式块名称匹配/复制和常用操作。
- 不要在首页放大段文字、属性编辑、属性填入、图库入库等不需要助手执行的流程。
- Excel 两列：图号、块名称。示例：
  - 图号：CRB01D2084
  - 块名称：CRB01D2084_垂直重锤拉紧装置_B500_08轴_D500
  - EXB 文件名：CRB01D2084_垂直重锤拉紧装置.exb
- 助手根据 EXB 文件名提取图号，精确匹配 Excel，提供复制块名称；用户自己粘贴并执行属性/入库。
- 用户已有的尺寸线层关闭和打散快捷键不重做。
- 不开发新的复杂全局快捷键，日常功能直接放在悬浮面板。
- 清理重复线、颜色归层、打开图层设置、全部图层打开不应依赖六视图计划；定义图符仍依赖四项/六项视图计划。

## 安全边界

- 基础签名任务只解除“未设置视图计划”这一项不必要的阻断；不解除源图哈希、工作副本路径、文件名唯一性和实时任务租约校验。
- 颜色归层仍需用户确认拾取过滤条件和高亮选集；不自动保存。
- 清理重复线由用户框选范围并确认。
- 定义图符仍要求完整视图计划。
- 属性编辑、标题栏属性填入、图符名称字段填入、最终图库入库均不由悬浮面板自动执行。
- 当前 CAXA 图纸核对只有在活动窗口标题精确包含工作副本文件名时才显示“图纸匹配”；同进程但标题不可识别时显示“无法确认”。

## 测试与交付要求

- Python 单元测试和 compileall 必须通过。
- AHK 主控制器及只读探针必须通过 AutoHotkey v2.0.32 parse-only。
- Windows CI 必须构建 PyInstaller onedir 包，并通过 --smoke-tk、--smoke-ahk、--check-job smoke tests。
- 测试 ZIP 必须含 program/CAXA助手.exe、program/_internal、runtime/vendor/AutoHotkey_2.0.32、app、runtime、独立启动 BAT。
- 用户实机验收必须用虚构测试图或真实图纸副本。先确认面板尺寸、图纸匹配、复制块名称和图层命令，再验证清理重复线和颜色归层。
- CI 通过不等于 CAXA 2024 实机自动化通过；PR #9 保持 Draft，不能据 CI 结果发布稳定版本。
