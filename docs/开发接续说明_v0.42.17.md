## 本轮修改：颜色筛选控件识别
用户反馈：点击面板颜色按钮会打开 CAXA「拾取过滤设置」对话框，但颜色复选框仍全部勾选，未自动筛选。

对 v0.42.16 AHK 代码复核发现，旧逻辑可能把“ControlGetChecked 返回 0 且 class=Button”的普通按钮或分组框误当作复选框。这是可确认的识别缺陷，但尚不能证明它就是用户电脑上唯一的失败原因。

v0.42.17 修改：
1. 新增 Win32 控件 style 读取。
2. 只将 BS_CHECKBOX、BS_AUTOCHECKBOX、BS_3STATE、BS_AUTO3STATE（style type 2/3/5/6）认作可操作复选框。
3. 颜色分组框按 BS_GROUPBOX（style type 7）识别，避免误把普通 Button 控件当作颜色分组。
4. 只读诊断报告新增 Style 字段，便于识别 CAXA 自绘控件、ListView 或 OwnerDraw 控件。
5. 控制器 build ID 更新为 caxa-helper-v0.42.17，旧版 AHK 进程不会被误认为新版本。

## 用户确认的规则（保持不变）
- 红色 → 中心线层
- 绿色 → 虚线层
- 蓝色 → 双点划线层
- 洋红色 → 细实线层
- 白色+黑白色 → 0层
- 颜色按钮只更改拾取过滤窗口中的颜色复选状态，不更改实体、尺寸、图层、线型筛选条件。
- 用户自行点击 CAXA 对话框“确定”，再框选对象。
- 一键特性按 Excel 规则设置图层、对象颜色 ByLayer、对象线型 ByLayer、比例 1、对象线宽 ByLayer；不弹二次确认。
- 不自动保存 EXB、不自动入库、不自动提交图库。
