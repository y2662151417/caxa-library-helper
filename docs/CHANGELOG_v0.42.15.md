# CAXA 图库助手 v0.42.15

## 本轮目标

按用户最新确认，把悬浮窗颜色筛选改为直接按钮；点击后自动设置 CAXA 拾取过滤对话框的颜色勾选。取消一键设置特性的二次确认，并按 Excel 规则直接修改当前选集。修复面板请求过期和控制器等待期间的重复校验开销。

## 已实现（代码层）

- 悬浮面板由颜色下拉框改为五个直接按钮：红色、绿色、蓝色、洋红色、白色+黑白色；另有恢复全选。
- CAXA 拾取过滤自动化定位标题为“拾取过滤设置”的当前任务对话框，只操作颜色分组；不修改实体类型、尺寸、图层和线型过滤条件。
- 自动先清除颜色列表其他勾选，再勾选目标颜色；白色+黑色会同时勾选两项。恢复全选通过颜色分组的“全有”按钮完成。
- 颜色复选框状态会逐项读回；标准颜色组识别不完整、状态不符、任务/窗口变化时失败关闭，不使用猜测坐标。
- 颜色按钮启动前检查旧选集数量；存在旧选集时要求操作者先按 Esc 清除。属性动作与最近一次颜色筛选、当前任务签名绑定，并要求过滤对话框已关闭、选集非空。
- 一键设置特性取消二次确认，按 Excel 规则发送目标图层、对象颜色、对象线型、对象线宽；首次使用需在设置中校准四个常用属性工具栏下拉框。
- 工具栏下拉框读回不再被当作实体修改成功的唯一证据；还要求左侧特性栏的图层、颜色、线型、线宽和线型比例读回符合目标。任何字段不一致都提示检查，不自动保存。
- 线型比例当前只读取并核验是否已等于 Excel 目标值；若不一致，当前版本会停止，不修改其他属性。比例字段自动写入仍待左侧属性控件诊断后实现。
- 新增“诊断左侧特性栏（只读）”，输出选集数量、五项属性值和 Win32 控件元数据，不读取图纸文字、几何、截图，不点击、不修改、不保存。
- 面板请求过期改用 Python 写入的 Unix epoch created_at 与 AHK A_NowUTC 比较，窗口扩大到 300 秒；活动任务签名和 35 秒实时工作台租约仍然保留。过期时写入不含图纸信息的 panel_action_expiry.log。
- findPickFilterDialog 的昂贵安全预检从每次 100ms 轮询中移出，只在等待循环前执行一次；循环内仍持续核对当前窗口、进程和任务签名，避免重复启动 Python 哈希校验进程导致 CAD 控制器阻塞。
- 新增颜色全状态验证、旧选集隔离、源颜色绑定、属性栏读回和请求过期逻辑测试。
