# CAXA 图库助手 v0.42.15

## 单键快捷键

- 将旧版 Ctrl+Alt、Ctrl+Alt+Shift 组合键替换为 F3–F12 单键操作；Pause 用于全局暂停/恢复。
- 快捷键仅在当前任务对应的 CAXA 进程/工作副本满足前台条件时生效；暂停后 F3–F12 交还给 CAXA。
- 设置窗口和快捷操作说明列出完整按键映射。
- 单层关闭、多层打开继续使用用户已经具备的 CAXA 原生图层管理操作；本版本不重新实现线层显示/隐藏。

## 颜色归层流程

- 保留按拾取过滤条件 Ctrl+A 选择对象的流程，并要求操作员检查高亮范围。
- 归层时将对象颜色、线型、线宽设为 ByLayer，再设置目标图层。
- 四个属性下拉框采用一次性校准；只支持可验证的标准 Win32 ComboBox/ComboBoxEx32 控件。
- 不自动保存图纸；尺寸层开关和打散仍使用用户已有快捷键；无尺寸视图复制继续暂缓。

## 验证边界

- Windows AutoHotkey v2 parse-only 检查此前通过。
- Python 单元测试此前因增量更新清单中的文件大小/哈希未同步而失败；本轮同步清单后重新运行 CI。
- F3–F12 的实际按键优先级、CAXA 2024 控件写入和图纸显示结果仍需用户在虚构测试图上实机验收。

## 只读诊断快捷键

- 独立只读控件探针由 Ctrl+Alt+Shift+F8 改为 F2；仅当配置的 CAXA 进程处于前台时接管 F2。
- Windows CI 现在分别对主控制器和独立只读探针执行 AutoHotkey v2.0.32 parse-only 检查。
