# 公开仓库内容范围

本仓库仅含 CAXA 助手程序源码、通用示例模板、更新清单和发布脚本。

明确不纳入：
- 任何 `.exb`、`.dwg`、`.dxf` 或其他真实 CAD 图纸；
- 用户真实图号、真实块名称和完整导入清单；
- 用户 SQLite 数据库、处理记录、工作副本和备份；
- 本机颜色模板、个人配置、控件诊断报告和运行日志；
- API 密钥、GitHub Token、证书、密码或其他凭据；
- 历史研发交接文件及包含个人项目细节的历史日志。

公开发布前应检查 GitHub Changes 列表和 `.gitignore` 状态。不要使用 `git add .` 后跳过审查。
