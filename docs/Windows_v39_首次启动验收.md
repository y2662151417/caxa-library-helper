# Windows v0.39 首次启动验收

1. 解压后根目录是否只有 `启动CAXA助手.bat` 一个文件入口及若干子文件夹。
2. 双击启动入口，是否能检测并调用本机 Python 3.10+ 与 Tkinter。
3. 是否启动紧凑制作面板。
4. 是否在本机 `logs/launcher.log` 记录启动过程。
5. 是否能通过 HTTPS 读取公开 GitHub Raw 更新清单；检查成功时，`logs/launcher.log` 是否记录 `更新检查完成：状态=current`；网络不可用时是否记录失败原因并正常启动本地版本。
6. 用户进度数据库和配置是否仍位于 `%LOCALAPPDATA%\CAXA_Library_Helper`。
7. 发布新版本后，是否只下载 SHA-256 不同的 `app/`、`runtime/` 程序文件；更新日志是否记录下载/替换文件数。
8. 模拟下载失败或哈希错误，是否保留旧版程序并继续启动。
9. 在 CAXA 2024 前台测试置顶面板、焦点和 CAD 控件调用。

前 8 项可在不打开真实图纸的情况下验收；第 9 项必须在目标 Windows + CAXA 2024 电脑上验收。
