# CAXA 图库助手 v0.42.8

## 本轮范围：一键只读扫描 CAXA 可见窗口

- 移除集成控件诊断中的 0—5 阶段输入框。
- 一次扫描自动枚举当前任务绑定的 CAXA 进程内所有可见顶层窗口，主绘图窗口始终优先记录。
- 对每个窗口记录 HWND、窗口类名、屏幕位置、控件 ClassNN、控件 HWND 和控件位置；不记录窗口标题、控件文本、图纸内容、参数或截图。
- 扫描前后继续校验任务签名、工作副本身份、进程 PID 和窗口类名。
- 不激活窗口、不点击、不发送 CAD 命令、不修改或保存 EXB。
- 为控制报告大小，最多记录 20 个窗口、每窗口 300 个控件、总计 1200 个控件。
- 输出文件统一命名为 controls_all_*.txt，保存在当前配置数据目录的 diagnostics 子目录。

## 验证边界

- Python 编译、单元测试及增量更新清单哈希检查由 GitHub Actions 验证。
- AHK v2 语法和 CAXA 2024 窗口枚举仍需 Windows 实机验证。
- 该版本只改进只读诊断，不执行尺寸线切换、无尺寸复制、图形修改或图库提交。
