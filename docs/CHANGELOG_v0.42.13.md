# CAXA 图库助手 v0.42.13

## 颜色归层第一阶段

- 将颜色规则简化为“源颜色 → 目标图层”；目标图层的颜色、线型和线宽由 CAXA 图纸中的图层预设维护。
- 默认映射：红色 → 中心线层；绿色 → 虚线层。白色暂不自动映射。
- 清理图纸窗口新增颜色归层入口：打开拾取过滤、应用目标图层、恢复拾取过滤、编辑映射。
- 新增一次性属性面板图层下拉框校准；只允许标准 ComboBox/ComboBoxEx32 控件，目标图层选择后必须读回一致。
- 操作仍要求用户先过滤源颜色、框选机械视图区域并确认当前选集；不自动保存图纸。
- 本轮不开发尺寸线层开关、打散快捷键；无尺寸视图复制暂缓。

## 验证边界

- 代码具备标准图层下拉框的校准与赋值路径，但尚未在用户的 CAXA 2024 实机验证。
- 如果 CAXA 属性面板使用自绘控件，当前自动化会停止，不会退化为猜测坐标点击。
- 仅改变对象图层不保证显式颜色/线型覆盖属性自动继承；需用虚构测试图验证 ByLayer 行为。
