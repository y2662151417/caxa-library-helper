# CAXA 图库助手 v0.42.13

## 正式块名称 Excel 数据源

- 新增标准库 XLSX 读取：第一张可见工作表 A 列图号、B 列正式块名称。
- Excel 是正式块名称唯一数据来源；UI 不再提供 TXT/CSV 导入入口，也不扫描图库文件夹猜测名称。
- 重复图号、重复正式名称、前缀不一致、空单元格、公式和第三列非空数据均拒绝导入；验证完成前不清除旧映射。
- 精确匹配仍基于 EXB 文件名第一个下划线前的完整图号。

## 当前图纸核验与剪贴板

- 增加只读 CAXA 窗口身份核验；复制前检查登记工作副本、源图路径安全性及 CAXA 窗口标题中的完整工作副本文件名。
- 未匹配、无工作副本、未绑定 CAXA、标题无法识别或当前图纸不一致时，拒绝复制。
- Windows 剪贴板读取改为优先使用 CF_UNICODETEXT，避免 Tk STRING selection 的 Unicode 读取问题。

## 悬浮窗与人工入库边界

- 首页增加“复制正式块名称”入口；无唯一匹配时禁用。
- 更多操作移除“属性与入库”入口。
- 关闭 Symdef 后的自动名称字段填写；不自动点击最终入库，不自动提交、不自动保存。
- 保留图符定义的原生命令入口、视图人工框选与基点确认。

## 验证边界

- 新增 Excel、共享字符串、重复图号保留旧映射、CAXA 标题精确匹配、剪贴板 UTF-16 解码和人工入库边界测试。
- 本轮尚未完成 Windows + CAXA 2024 实机验收；CAXA 窗口标题若不显示工作副本 EXB 文件名，复制将按安全策略拒绝。
- 常用清理、图层和颜色操作仍有完整任务校验依赖；后续需单独拆分并验证，不在本轮绕过安全校验。
