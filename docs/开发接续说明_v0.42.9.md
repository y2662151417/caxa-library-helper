# CAXA 图库助手｜开发接续说明 v0.42.9

日期：2026-11-26

## 本轮目标

用户明确要求：日常助手保持小窗口；选择图纸时不要再打开包含全部管理功能的大窗口；选中图纸后必须有明显的下一步「打开图纸」操作。

## 当前结构

- 标准启动器设置 CAXA_MINI_PANEL=1。
- 完整批量管理工作台仍由 Tk root 构建，但标准启动时隐藏。
- 小型悬浮助手保留原有尺寸。
- 点击悬浮助手「选择图纸」时，打开独立 DrawingSelector（680×460），不再 deiconify 完整工作台。
- 选择窗口只包含目录选择、刷新、搜索、图纸列表、选择状态、打开工作副本、更多管理、关闭和退出。
- 点击「更多管理」才显式显示完整工作台；关闭该窗口只隐藏管理工作台，不退出助手。

## 选图操作流程

1. 点击悬浮助手「选择图纸」。
2. 若尚无目录，点击「选择目录」并选 EXB 根目录；扫描会排除配置的工作副本、完成图库等目录。
3. 单击目标图纸行，窗口底部显示「已选择：图号｜图名。下一步：点击打开工作副本」。
4. 点击「打开工作副本」，程序先调用 core.ensure_working_copy，再通过系统关联程序请求打开工作副本；不直接编辑源 EXB。
5. 打开成功后选择窗口关闭，悬浮助手恢复置顶。

## 保留的功能

原批量管理工作台不删除，仍包含名称清单导入、参数记录、视图计划、人工验收、备份、CSV 导出、操作历史和异常检查。它只从日常选图路径中移出，需通过「更多管理」显式打开。

## 安全边界

- 不修改原始 EXB；只创建/打开登记的工作副本。
- 不自动保存、关闭当前 CAXA 文档或确认 CAD 弹窗。
- 不自动框选图元、指定基点、修改图层或提交图库。
- 选图成功不等于快捷任务已通过预检；仍由现有任务签名和 preflight 规则决定助手可执行哪些动作。

## 实机验收清单

- 标准启动后只出现小型 CAXA 制作助手，不出现完整批量管理窗口。
- 点击「选择图纸」后出现约 680×460 的独立选择窗口。
- 窗口不被悬浮助手遮挡；关闭后悬浮助手恢复置顶。
- 选择目录、搜索图号/图名、单击选中、双击打开均可用。
- 选中后「打开工作副本」按钮清晰可见；打开成功后选择窗口自动关闭。
- 「更多管理」才显示完整管理工作台；关闭高级管理不退出助手。
- 「退出助手」执行原有安全退出流程。
