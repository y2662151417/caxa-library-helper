# CAXA 图库助手｜开发接续说明 v0.42.10

日期：2026-11-26

## 本轮目标

修复自动增量更新器直接替换 GitHub Desktop 本地仓库文件，造成 Changes 列表出现大量未提交修改、Pull 被阻止的问题。

## 规则

- 程序根目录存在 .git 目录或文件：按 Git 开发仓库处理，启动时跳过更新源读取和自动更新，只通过 GitHub Desktop Fetch/Pull 同步。
- 程序根目录不存在 .git：按独立运行目录处理，保留 HTTPS Manifest、SHA-256 校验、增量下载、备份和回滚。
- runtime/updater.py 的 check_from_install 与 apply_update 都有保护，避免其他调用入口绕过启动器策略。
- 迁移到E盘.bat 会复制 .git 元数据，因此迁移后的目录仍按开发仓库处理。
- 用户数据、EXB 图纸、工作副本和 update_source 配置不因本轮修改而迁移或删除。
