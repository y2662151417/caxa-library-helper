# CAXA 图库助手 v0.42.7

## 本轮范围：只读控件诊断

- 在悬浮面板「更多操作」中增加一个按需入口，不增加主面板常驻按钮。
- 控件诊断通过当前 AHK 控制器执行，使用当前任务签名、工作副本唯一窗口和实时安全校验。
- 支持绘图主窗口、图层设置（尺寸线层）、拾取过滤设置、左侧特性栏、定义图符、图符入库六个诊断阶段。
- 图层设置、拾取过滤和图符入库必须找到唯一 CAXA 对话框；不唯一则停止。
- 报告只记录进程名、窗口类名、控件类名和控件位置；不输出窗口标题、控件文本、图纸内容、参数或截图。窗口标题仅在本机用于核验工作副本身份，不写入报告。
- 不激活目标窗口，不发送 CAD 命令，不点击控件，不修改或保存 EXB。
- 报告写入当前配置的数据目录下的 `diagnostics` 子目录；修正独立探针的输出目录，使其优先使用 `CAXA_HELPER_DATA_DIR`。

## 验证边界

- Python 桥接测试与 GitHub Actions 编译检查通过后，才可合并。
- AHK v2 语法和 CAXA 2024 窗口枚举仍需用户 Windows 实机验证；本版本不声称已经识别出实际图层列表控件。
