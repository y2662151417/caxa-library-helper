## 用户确认的操作规则

- 原始颜色 → 目标图层：
  - 红色 → 中心线层
  - 绿色 → 虚线层
  - 蓝色 → 双点划线层
  - 洋红色 → 细实线层
  - 白色+黑白色 → 0层
- 目标对象颜色：ByLayer。
- 目标对象线型：ByLayer。
- 目标对象线型比例：1。
- 目标对象线宽：ByLayer。
- 面板要小型自用工具窗，不能做成大面积展示面板。
- 主面板直接显示颜色下拉、拾取筛选、一键设置特性、删除重线、定义属性块、复制正式块名称。
- 属性填写、最终图库入库、提交和保存均由用户在 CAXA 中人工完成。

## Excel 结构

### 图纸映射表（第一张可见工作表 A-C）

- A：图号
- B：EXB 文件名
- C：正式块名称

例如：
- CRB01D2084
- CRB01D2084_垂直重锤拉紧装置.exb
- CRB01D2084_垂直重锤拉紧装置_B500_08轴_D500

程序按图号和 EXB 文件名双重匹配；块名称必须以图号加下划线开头。

### 颜色规则表（空行后）

- A：线层/目标图层
- B：线型
- C：线型比例
- D：线宽
- E：对象颜色
- F：原始颜色（推荐新增）

F 列用于标记颜色筛选来源。当前用户上传的旧表没有 F 列，程序按用户在对话中明确确认的五组默认映射初始化。若用户要在 Excel 中自助调整规则，补 F 列并填写五组源颜色。

Excel 导入一次后保存到本机 SQLite；不需要每次启动重新上传。更新 Excel 后重新导入即可。导入失败不得覆盖旧映射。

## 已知技术限制

1. 仅凭公开 CAXA 2018 手册可以确认 objectset 是拾取过滤设置命令；这不能证明 CAXA 2024 的窗口标题和控件 ID 完全一致。
2. 公开手册列出 laycur 移动对象到指定图层，但该命令不等于把对象颜色、线型、线宽统一改成 ByLayer；当前没有把 laycur 冒充成完整的一键特性修改。
3. 拾取过滤对话框若不是独立顶层窗口，当前 probePickFilterDialog 会报告未定位，不会猜测窗口。
4. properties 若打开为嵌入式停靠面板，当前 probePropertiesPanel 不会扫描主窗口/绘图区，需再设计安全的定向诊断。
5. 当前颜色过滤和属性操作仍依赖有效的已发布工作任务（包括视图计划）；工作副本独立校验与完整视图任务解耦尚未完成。
6. AutoHotkey v2 代码尚未在 CAXA 2024 实机验证；Python CI 不覆盖 AHK 或 CAD UI 行为。
