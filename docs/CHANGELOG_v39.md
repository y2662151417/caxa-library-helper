# v0.39.0 更新记录

## 本轮目标

将 CAXA 图库助手整理为单入口 Windows 程序目录，并建立不覆盖本机数据的增量更新机制。

## 变更

- 根目录仅保留 `启动CAXA助手.bat` 一个日常启动入口。
- 将业务代码归入 `app/`，AutoHotkey 脚本归入 `app/快捷键工具/`，内置模板归入 `app/resources/`。
- 将稳定启动器和增量更新器放入 `runtime/`。
- 将更新源配置、暂存和回滚目录放入 `updates/`。
- 将使用说明、更新机制和导入模板放入 `docs/`。
- 进度数据库、用户模板、导入的名称清单、运行时和备份继续放在 `%LOCALAPPDATA%\\CAXA_Library_Helper`，与安装目录隔离。
- 配置公开 GitHub Raw 更新清单；客户端按 SHA-256 比较，只下载变化的 `app/`、`runtime/` 程序文件。
- 更新前先下载并校验全部变更文件，替换前备份旧文件；失败时回滚。
- 更新清单不能覆盖根启动入口、更新源配置或用户数据目录。
- 更新失败时记录日志并继续启动上一个可用版本。

## 当前限制

- 首次仍需部署完整文件夹。
- 启动依赖电脑现有 Python 3.10+ 和 Tkinter。
- 首次使用 CAD 控制器时需要联网下载 AutoHotkey 官方便携运行时。
- GitHub Raw 访问受本机网络环境影响；无法访问更新源时会跳过更新并尝试启动本地版本。
- 自动化流程仍是 CAXA 半自动辅助；Windows + CAXA 2024 实机操作仍需用户验收。
