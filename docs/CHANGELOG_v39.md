# v0.39.0 更新记录

## 本轮目标

解决用户不希望解压后看到大量文件，以及每次程序更新都重新下载完整安装包的问题。

## 变更

- 根目录仅保留 `启动CAXA助手.bat` 一个可见启动入口。
- 将业务代码归入 `app/`，AutoHotkey 脚本归入 `app/快捷键工具/`，内置模板归入 `app/resources/`。
- 将稳定启动器和增量更新器放入 `runtime/`。
- 将更新源配置、暂存和回滚目录放入 `updates/`。
- 将使用说明、更新机制和导入模板放入 `docs/`。
- 将启动日志放入 `logs/`。
- 进度数据库、用户模板、导入的名称清单、运行时和备份继续放在 `%LOCALAPPDATA%\CAXA_Library_Helper`，与安装目录隔离。
- 新增 HTTPS manifest 增量更新：逐文件 SHA-256 比较、仅下载变更文件、先暂存校验、备份旧文件、失败回滚。
- 更新清单只允许替换/删除 `app/`、`runtime/` 程序文件，不能覆盖根启动入口、更新源配置和用户数据。
- 更新失败时记录日志并继续启动上一个可用版本。
- 内置更新源暂时留空，等待用户批准托管位置；不会擅自上传源码。

## 当前限制

- 首次仍需部署完整文件夹。
- 自动更新引擎已集成，但远程更新源未配置，故尚不能联网自动更新。
- 启动仍依赖电脑现有 Python 3.10+ 和 Tkinter。
- 本轮没有 Windows + CAXA 2024 实机验证。
