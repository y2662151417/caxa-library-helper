4. `app/快捷键工具/CAXA_控件探针_只读.ahk`：增加图层设置阶段，并优先将报告写入 `CAXA_HELPER_DATA_DIR`。

6. `app/VERSION.txt` 和 `updates/manifest.json`：版本提升至 v0.42.7，更新文件哈希。

## 只读报告内容

只记录进程名、窗口类名、控件类名和控件位置。不读取窗口标题、控件文字、图纸文本、参数、实体内容或截图。不会激活窗口、点击控件、发送 CAD 命令、修改或保存 EXB。报告存放在当前配置数据目录的 `diagnostics` 子目录。

## 下一步

1. 用户先启动程序并确认增量更新到 v0.42.7。
2. 用一张自制虚构 EXB，分别打开「图层设置」「拾取过滤」「左侧特性」「定义图符」「图符入库」等阶段，逐次运行只读诊断。
3. 将六个阶段的报告用于判断控件是否为标准 Windows 控件、哪些控件可枚举、是否存在稳定的类名/几何位置。
4. 只有报告证明目标控件稳定且唯一后，才设计尺寸线层切换或属性填入辅助。若是自绘/UIA 控件或行顺序不稳定，则继续人工操作，不按坐标盲点。
5. 不拿正式公司 EXB 做第一轮验证；不自动确认图库提交或保存。
