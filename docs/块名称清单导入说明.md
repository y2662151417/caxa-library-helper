# 正式块名称清单导入说明

## Excel 格式（推荐）

提供一个 .xlsx 文件，使用第一张工作表，前两列分别为：

| 图号 | 块名称 |
|---|---|
| CRB01D2084 | CRB01D2084_垂直重锤拉紧装置_B500_08轴_D500 |

列标题必须是“图号”和“块名称”。一行对应一个图号。不要合并单元格，不要在块名称前后添加说明文字。

程序使用 Python 标准库读取 xlsx，不要求安装 openpyxl。

## 兼容格式

### CSV：两列

    图号,块名称
    CRB01D2084,CRB01D2084_垂直重锤拉紧装置_B500_08轴_D500

### TXT：每行一个完整块名称

    CRB01D2084_垂直重锤拉紧装置_B500_08轴_D500

TXT 方式从第一个下划线前提取图号。

## 匹配规则

- EXB 文件名格式：图号_图纸名称.exb。
- 例如 CRB01D2084_垂直重锤拉紧装置.exb，图号为 CRB01D2084。
- 只按第一个下划线前的完整图号精确匹配，大小写不敏感。
- 块名称的第一个下划线前缀必须与图号一致。
- 不使用相似前缀、模糊标题或编号截断来猜测。
- Excel 中存在重复图号或重复块名称时，整份导入会被拒绝。
- 同图号对应多张 EXB 时标记为冲突，不会自动匹配。
- 未匹配或存在冲突的图号不能复制块名称。

## 导入和使用

1. 打开 CAXA 制作助手悬浮面板。
2. 点击“设置” → “导入 Excel 块名称清单”。
3. 选择 Excel 文件，检查导入报告中的匹配数量和未匹配项。
4. 在“选择图纸”中选中对应 EXB，并点击“打开图纸”创建/打开工作副本。
5. 悬浮面板显示“块名称：已匹配”后，点击“复制块名称”。
6. 操作者自行将名称粘贴到 CAXA 的图符名称字段，并继续属性核对和图库入库。

助手只负责匹配和复制，不自动填写属性、不自动点击入库、不自动保存 EXB。清单只保存在本机用户数据目录，请勿将真实块名称清单提交到公共仓库。
