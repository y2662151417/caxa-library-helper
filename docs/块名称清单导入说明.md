# 图符名称清单导入说明

## 目的

将每张 EXB 图纸对应的正式块名称导入工作台。程序依据完整图号匹配；匹配成功后，当前图纸任务会把正式块名称传给 CAD 辅助控制器。

## 支持格式

### TXT：每行一个完整块名称

```text
SAMPLE-001_设备示例_规格A
SAMPLE-002_设备示例_规格B
```

程序取第一个下划线前的完整图号作为匹配键。

### CSV：两列

```csv
图号,块名称
SAMPLE-001,SAMPLE-001_设备示例_规格A
SAMPLE-002,SAMPLE-002_设备示例_规格B
```

块名称本身带图号前缀时，前缀必须与第一列完全一致。

## 匹配规则

- EXB 文件名格式：`图号_图纸名称.exb`。
- 只比较第一个下划线前的完整图号，大小写不敏感。
- 不使用相似前缀、模糊标题或编号截断来猜测。
- 同图号对应多张 EXB 时标记为冲突，不会自动匹配。
- 未匹配的图号不会自动填入 CAD。

## 工作台操作

1. 扫描包含 EXB 文件的目录。
2. 点击“导入图符名称清单”，选择 TXT 或 CSV。
3. 查看导入报告中的匹配数量和未匹配项。
4. 选中图纸，检查正式图符名称及匹配状态。
5. 只有状态为“已匹配”时，辅助控制器才允许填写正式块名称。

导入清单只保存在本机，不会修改 EXB、原图或工作副本。请勿将真实块名称清单提交到公共仓库。
