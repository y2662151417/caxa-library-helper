## 本轮改动

当前 probeCaxaControls 已能枚举任务绑定 CAXA 进程的所有可见顶层窗口，并记录 ClassNN、HWND、位置。此前缺少真实 Win32 类名、Dialog Control ID、Visible/Enabled 状态和样式值，无法充分区分按钮、列表、编辑框及自绘控件。

本轮增加：
- GetClassNameW：读取控件 Win32 类名。
- GetDlgCtrlID：读取控件 ID。
- IsWindowVisible / IsWindowEnabled：记录控件状态。
- GetWindowLongPtrW / GetWindowLongW：读取 GWL_STYLE 与 GWL_EXSTYLE。
- 继续不读取任何窗口标题、控件文本、图纸内容、参数或截图。
- 不激活窗口、不点击、不发送 CAD 命令。

## 下一步

1. 合并后，用户在 GitHub Desktop 拉取更新。
2. 使用自制虚构 EXB 打开 CAXA 2024。
3. 在 CAXA 中打开“图层设置（尺寸线层）”窗口，保持它可见。
4. 悬浮助手 -> 更多操作 -> 只读诊断 CAXA 控件，一次扫描当前绑定 CAXA 进程全部可见窗口。
5. 把 diagnostics/controls_all_*.txt 报告发回本开发对话。
6. 根据真实 Win32 类名、控件 ID、样式与位置判断是否能用标准 Win32 控件接口可靠读取/操作。若为自绘或 UIA-only 控件，再研究 UI Automation；不能先写坐标猜测。
