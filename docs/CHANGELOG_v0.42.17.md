# CAXA 图库助手 v0.42.17

## 悬浮面板精简

- 首页调整为约 330×350，移除长篇操作说明、视图模板摘要、继续任务主按钮、其他工具入口和“属性与入库”入口。
- 首页只显示当前图纸、块名称匹配状态、复制块名称、当前 CAXA 图纸核对，以及清理重复线、颜色归层、图层设置、全部图层打开和定义图符。
- 设置页增加 Excel 块名称清单导入入口。
- 当前图纸显示的是已选择的源图；“核对图纸”会由 AHK 读取当前 CAXA 活动窗口标题，只有精确匹配工作副本文件名才报告匹配。

## 正式块名称匹配

- 新增 .xlsx 第一工作表前两列读取，列名为“图号”和“块名称”。
- 使用 Python 标准库 zipfile/XML 读取，不引入 openpyxl 依赖。
- 保留原有 TXT/CSV 导入和完整图号精确匹配规则。
- 匹配成功后由用户点击“复制块名称”；助手不自动填写属性、不执行图库入库。

## 日常 CAD 操作任务解耦

- 选择图纸并创建有效工作副本后，即可发布不带视图计划的基础签名任务。
- 清理重复线、颜色归层、图层设置和图层全开不再因未配置六视图计划而全部被拦截。
- “定义图符”仍要求已核对的四项双视图或六项三视图计划；不降低这项安全门槛。
- 增加当前 CAXA 活动窗口图纸核对请求；未能确认时明确显示未知，不把未知当成匹配。

## 剪贴板错误提示

- 对 Tk 剪贴板中不存在普通文本的情况增加中文提示，不再直接暴露 Tcl 的底层错误文本。

## Windows 独立运行包

- Windows 测试包使用 PyInstaller onedir 方式打包 Python 3.11、Tk/Tcl 和应用程序；目标电脑无需安装 Python。
- 将通过 SHA-256 校验的 AutoHotkey v2.0.32 便携运行时随包分发，并保留其许可证；首次启动复制到独立用户数据目录，不依赖首次联网下载。
- AHK 安全校验器通过同一个打包 EXE 的 --check-job 命令行模式运行，不再调用系统 Python。
- CI 增加 Tk/Tcl、内置 AHK 运行时和无 GUI 校验器分发的 Windows smoke tests。
- 测试包关闭自动更新，用户数据独立保存在 %LOCALAPPDATA%\CAXA_Library_Helper_TEST_0_42_17。

## 尚未通过的实机项目

- 当前 CAXA 2024 活动窗口标题能否稳定暴露工作副本文件名，需在用户电脑核验；无法识别时面板显示“无法确认”。
- 颜色归层仍依赖 CAXA 拾取过滤对话框和已校准的属性下拉框；需用测试图验证。
- 清理重复线、定义图符和 CAXA 2024 的实际命令响应仍需用户实机验收。
- PR #9 继续保持 Draft；实机验收通过前不合并 main、不发布稳定版。
